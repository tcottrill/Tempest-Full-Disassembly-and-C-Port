CAM enemy motion scripts (ALWELG CAM $A0F7-$A18F, TABJSR $9BA2)

Byte code run by MOVINV once per enemy per frame until VEXIT. 2-byte branch operands hold target-CAM-1. Flipper script per wave (CAMWAV, wave-1 & 15): 1:NOJUMP, 2:MOVJMP, 3:SPIRAL, 4:SPIRCH, 5:COWJM2, 6:MOVJMP, 7:SPIRCH, 8:SPIRAL, 9:COWJM2, 10:AVOIDR, 11:SPIRCH, 12:SPIRAL, 13:COWJM2, 14:NOJUMP, 15:AVOIDR, 16:SPIRCH

Script:
Schematic: circular well, player claw (NCRS1) on lane 0 at the rim, flipper drawn with INVA1 between the two lane points. VSMOVE moves up, VJUMPS/VJUMPM flip over the pivot corner (8 steps), VEXIT ends the frame.
